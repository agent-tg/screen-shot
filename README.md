# Screen Shot

Screen Shot is a macOS app for capturing screenshots, copying and saving them, and adding annotations.

[Download the latest release](https://github.com/agent-tg/screen-shot/releases/latest)

Requires macOS 14 or later. The release includes support for Apple silicon and Intel Macs.

## Install

Download the release ZIP, unzip it, and move **Screen Shot.app** to **Applications**. Open the app and allow Screen Recording access when macOS asks.

Use the camera icon in the menu bar to capture a selection, a window, or a screen. Open **Settings** to assign your preferred shortcuts. Shortcut assignments and macOS permissions are local to each Mac.

## Updates

Choose **Check for Updates…** from the Screen Shot menu to check for a newer release. The app also offers automatic update checks.

This repository contains app downloads, release notes, and the signed update feed. Source code is maintained separately.
