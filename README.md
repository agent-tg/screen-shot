# Screen Shot

Screen Shot is a macOS app for capturing screenshots, copying and saving them, and adding annotations.

[Download the latest release](https://github.com/agent-tg/screen-shot/releases/latest)

Requires macOS 14 or later. The release includes support for Apple silicon and Intel Macs.

## Install

Download the release ZIP, unzip it, and move **Screen Shot.app** to **Applications**. Open the app and allow Screen Recording access when macOS asks.

In System Settings → Privacy & Security → Screen & System Audio Recording, enable Screen Shot in the upper screen-recording list. The lower System Audio Recording Only list does not allow screenshots. Quit and reopen the app after changing its permission.

Use the camera icon in the menu bar to capture a selection, a window, or a screen. Shortcut assignments and macOS permissions are local to each Mac.

## Edit shortcuts

Click **Edit Shortcuts…** in Recent Screenshots, or use **Settings…** in the menu. Record any key combination macOS can register, including ⌘X. Global shortcuts can replace normal typing and app commands, so choose the keys you want Screen Shot to own while it is running.

If a shortcut is already assigned to another row, clear or change it there before moving it. For example, ⌘X on Capture Selection (Alternate) already triggers selection capture. macOS registration conflicts are reported without replacing the previous working assignment.

## Updates

Choose **Check for Updates…** from the Screen Shot menu to check for a newer release. The app also offers automatic update checks.

This repository contains app downloads, release notes, and the signed update feed. Source code is maintained separately.
